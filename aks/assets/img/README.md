# Images

Empty by design. Every visual in the current build is inline SVG acting as a
placeholder.

Suggested naming when real photography arrives:

```
hero-tee.jpg              hero garment (replaces the .hero-tee <svg> in index.html)
collection-{slug}.jpg     collection tiles
product-{slug}.jpg        product cards
ig-{1..5}.jpg             Instagram grid
```

Export at 2× the rendered size, compress, and prefer WebP with a JPG fallback.
